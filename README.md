# MWP — My Wealth Planner

A full-stack personal finance planning application built with the MERN stack. MWP helps users manage their finances, track investments, plan financial goals, and explore useful financial calculators.

## Live Demo

[View Live Demo](https://my-wealth-planner.onrender.com/)

## Features

* User registration and login
* JWT-based authentication
* Forgot and reset password through email
* Financial profile and risk assessment
* Financial dashboard with an overview of user finances
* Income and expense transaction tracking
* Monthly category-based budgets with progress tracking
* In-app budget alerts using toast notifications
* Holdings tracking for Gold, Stocks, FDs, and RDs
* Financial goal planning with inflation-adjusted target amounts
* Goal contribution tracking with progress indicators
* Risk-profile-based investment allocation suggestions
* Financial calculators including SIP, EMI, CIBIL Score, Retirement Corpus, and Inflation
* Selected calculators available without login through the landing page
